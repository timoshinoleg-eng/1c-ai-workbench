**Тело поста:**

Коллеги, открыта публичная beta **1C AI Workbench v0.10.0-beta.1** — локального
инструмента, который индексирует XML-выгрузку конфигурации 1С и отдаёт
структурированные ответы AI-клиенту (opencode, Cursor, VS Code, desktop MCP
client) с доказательствами: путь к файлу, объект, процедура, фрагмент кода и
уровень уверенности.

**Что умеет сейчас:**

- локальный поиск и индексация BSL-кода и метаданных (Rust-индексатор);
- read-only MCP-инструменты: `meta_info`, `form_info`, `skd_info`, `role_info`,
  `cf_info` и другие;
- галерея callable-подсказок: explain-module, find-object, review-bsl,
  trace-flow;
- healthcheck и demo-витрина для быстрого знакомства;
- offline-установка Python-зависимостей из проверенного wheelhouse.

**Кому полезно:** 1С-разработчикам, техлидам, аналитикам и партнёрам, кто хочет
быстро ориентироваться в большой или чужой конфигурации и получать от AI не
догадки, а локальные доказательства.

**Важно про безопасность (честно):**

- Это **unsigned beta**: installer без коммерческой Authenticode-подписи.
  Windows SmartScreen покажет «Неизвестный издатель» — это ожидаемо.
- Перед запуском сверьте SHA-256 и GitHub Actions run, который собрал файл.
  Инструкция — в `docs/BETA_TESTING.md`.
- Мы не используем self-signed сертификат и не просим отключать Defender или
  SmartScreen.
- Продукт локальный и read-only: не пишет в 1С и не загружает вашу выгрузку
  наружу. Фрагменты кода могут уйти AI-провайдеру только через ваш MCP-клиент.

**Ограничения beta:**

- требуется 64-bit CPython 3.11;
- нет portable ZIP (пока технически не готов, фиктивный не публикуем);
- не для production-баз без резервной копии — работайте с выгрузками и
  демо-данными;
- только Windows 10/11 x64; возможны предупреждения и шероховатости.

**Как попробовать (5 минут):**

1. Скачать installer из GitHub Release `v0.10.0-beta.1` (помечен Pre-release).
2. Сверить SHA-256 (`Get-FileHash`) с `checksums.txt`.
3. Установить (per-user, без админ-прав).
4. `.\scripts\setup.ps1 -Offline -SkipBinaryDownload`
5. `.\scripts\06_healthcheck.ps1` → открыть `generated\reports\readiness-report.md`.
6. `.\scripts\11_open_demo_showcase.ps1` → demo-витрина.

Подробный разбор, проверка источника, privacy, удаление и FAQ — в
`docs/BETA_TESTING.md` и `docs/BETA_SECURITY.md`.
